# Absolute Motion Pvt. Ltd. — Landing Page

> **Human-Centered Industrial Automation & Engineering Showcase**  
> *"Where connection transforms into control, and control awakens into consciousness."*

A modern, high-performance, responsive landing page engineered for **Absolute Motion Pvt. Ltd.** inspired by sleek glassmorphism and developer-centric aesthetic.

---

## 🌟 Key Features

- **Dynamic Interactive Link Showcase**:
  - **Inline Embedded Video Player**: Plays the YouTube showcase (`8LESD0vInaA`) directly inline without external redirects.
  - **Control Panel Manufacturing**: Custom industrial control panels engineered for dust, heat, and high-demand environments.
  - **OEM Machine Integration**: Synchronization of PLCs, HMIs, and motion drives with human-centered precision.
  - **Industry 4.0 & Smart Telemetry**: Industrial data analytics, IoT telemetry, and predictive maintenance.
  - **Prayas Academy & Training Labs**: Practical automation and engineering skill development.
  - **Our Story & Philosophy**: Authentic company narrative from [absolutemotion.in](https://absolutemotion.in/).
- **Category Filter Tabs**: Fast, client-side filtering for *Control Panels*, *OEM Integration*, *Industry 4.0*, and *Prayas Academy*.
- **Official Social Navigation**: Verified links to Instagram, Facebook, and LinkedIn.
- **Interactive Quick Consultation Modal**: Built-in modal for direct engineering inquiry and contact details.
- **Responsive QR Panel**: Quick mobile access trigger with scan-to-device capability.
- **Pure Web Standards**: Built using vanilla HTML5, modern CSS3 (with CSS variables and backdrop-filter glassmorphism), and lightweight vanilla JavaScript.

## 🚀 Getting Started

You can run this project locally using any simple HTTP server or directly in your browser:

### Option 1: Python HTTP Server
```bash
python -m http.server 8080
```
Then navigate to: `http://localhost:8080/`

### Option 2: Node.js (npx serve)
```bash
npx serve .
```

### Option 3: Direct File Opening
Double-click `index.html` to open it in Google Chrome, Microsoft Edge, or any modern web browser.
